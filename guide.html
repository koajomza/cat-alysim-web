Start Guide

คู่มือเริ่มใช้งานแบบรวบรัด ตั้งแต่สร้างคดี ใส่ข้อมูลคน เพิ่มหลักฐาน ไปจนถึง Generate เอกสาร Word

สร้างคดีกรอกเลขคดี ข้อหา วันเวลา สถานที่เกิดเหตุ และข้อมูลพื้นฐานให้ครบก่อน
เพิ่มบุคคลใส่ผู้กล่าวหา ผู้ต้องหา พยาน หรือบริษัท/ผู้รับมอบอำนาจตามประเภทคดี
เพิ่มทรัพย์และหลักฐานบันทึกรายการทรัพย์ ของกลาง เอกสาร หรือข้อมูลประกอบสำนวนที่ต้องใช้ใน Template
Generate เอกสารเลือก Template แล้วให้ระบบดึงข้อมูลลง Word จากนั้นเปิดตรวจรูปแบบและข้อความก่อนใช้จริง
ตรวจและบันทึกตรวจชื่อ วันที่ ข้อหา และช่องว่างทุกครั้ง เพราะระบบช่วยเร็วขึ้น แต่คนยังต้องคุมความถูกต้องอยู่ดี
